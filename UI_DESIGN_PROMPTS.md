## Design Guidelines for All Screens

**Color Palette (Monochrome Only):**
- Background: Pure black (#000000)
- Surface: Dark gray (#1a1a1a, #2a2a2a)
- Borders: Subtle gray (#333333, #404040)
- Text Primary: White (#ffffff)
- Text Secondary: Light gray (#a0a0a0)
- Text Tertiary: Medium gray (#666666)
- Accent: White with opacity variations
- Hover: Lighter gray (#2a2a2a → #353535)

**Typography:**
- Headings: Bold, large (32-48px), white
- Body: Regular (14-16px), light gray (#a0a0a0)
- Labels: Small (12-14px), medium gray (#666666)
- Font: Modern sans-serif (Inter, Helvetica, or similar)
- NO colored text - only grayscale

**Effects:**
- NO gradients - solid colors only
- Subtle shadows: Black with low opacity (rgba(0,0,0,0.5))
- Borders: 1px solid gray (#333333)
- Hover: Slight brightness increase or border highlight
- Rounded corners: 8-12px (minimal)
- Transparency: Use sparingly for depth

**Layout:**
- Max width: 1280px centered
- Padding: 24-48px
- Grid gaps: 16-24px
- Card spacing: Consistent
- Minimal whitespace
- Clean, structured layouts

**Icons:**
- Monochrome only (white or gray)
- Size: 20-24px for UI, 32-48px for headers
- NO colored icons

**Visual Style:**
- Minimal, clean, professional
- High contrast (white on black)
- NO vibrant colors
- NO gradients
- Subtle depth through shadows and borders
- Focus on typography and spacing
- Similar to: Linear, Vercel, GitHub dark mode, or Stripe

## Usage Instructions

1. Copy the prompt for the screen you want to design

3. Generate multiple variations
4. Select the best design
5. Use as reference for implementation

**Note:** These prompts create clean, minimal, monochrome UIs without device mockups. The designs use only black, white, and grays for a professional, modern aesthetic.

## Project Root
```

├── frontend/           # Vite + Vanilla JS + Phaser.js client
├── backend/            # Node.js + WebSocket game servers
├── contracts/          # Solidity smart contracts
├── docker-compose.yml  # Multi-container orchestration
```

## Key Architecture Features

### Frontend
- **Lazy Loading**: Each game loads only when selected
- **Registry-Based**: All games listed in `games.json`
- **Scalable UI**: Supports 200+ games without performance issues
- **Web3 Integration**: Wallet connection & contract interaction
- **Modular Games**: Each game is self-contained

### Backend
- **Microservices**: Each game has its own WebSocket server
- **Redis Pub/Sub**: Cross-server communication
- **Horizontal Scaling**: Can run multiple instances
- **Authoritative Server**: All game logic server-side
- **Queue System**: Smart matchmaking & arena management

### Smart Contracts
- **Single Economy**: One contract manages all games
- **Escrow System**: Safe prize pool management
- **Game Registry**: Easy to add new games
- **Transparent**: All transactions on-chain
